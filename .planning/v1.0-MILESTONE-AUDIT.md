## 3. Cross-Phase Integration & End-to-End Flows

### Flow 1: Pendaftaran Jalur & Kunci Balapan (Lock Heat)
- Peserta memindai QR Code jalur A, B, atau C dengan HP (`ParticipantDashboard.jsx`).
- Tombol `SIAP BALAP` ditekan -> Race Director menekan `KUNCI BALAPAN (LOCK HEAT)` di `RaceDirectorDashboard.jsx`.
- Saldo kupon terdebit 1 kupon secara atomik di database (`server/raceManager.js:lockRace`), balapan berstatus `pre-start`.
- **Status:** **PASS**

### Flow 2: Penanganan Darurat Crash Masal (Semua CO/DNF)
- Mobil meluncur di trek, namun semua mobil keluar lintasan / rusak.
- Race Director menekan tombol merah `SEMUA CO / DNF (NO WINNER)`.
- Database mengupdate race menjadi `completed`, `winner_id = NULL`, status registrasi menjadi `dnf_co`. Kupon peserta tetap terpotong sah.
- Socket event `RACE_ALL_CO` memancarkan notifikasi ke TV Sirkuit dan HP peserta.
- **Status:** **PASS**

### Flow 3: Deklarasi Balap Ulang (Re-Race)
- Terjadi insiden eksternal di lintasan.
- Race Director menekan tombol `DEKLARASI RE-RACE`, memilih jalur yang berhak tanding ulang via modal checklist (`[x] Jalur A`).
- Database mereset status jalur terpilih ke `ready`, mengembalikan race ke `pre-start`.
- Saldo kupon pembalap **tidak dipotong ganda** dan pembalap **tidak perlu scan QR ulang**.
- Socket event `RACE_RERACE_DECLARED` memicu alarm sirene dan banner alert di TV sirkuit.
- **Status:** **PASS**

### Flow 4: Meja Pemeriksaan Scrutineer Lapis 2 & Lapis 3
- Pemenang balapan tiba di meja juri fisik dengan membawa mobil.
- Jika laptop Race Director terlambat / terputus: Tablet Scrutineer menampilkan **Active Alert Lapis 2** berkedip kuning: *"RACE AKTIF BELUM DISUBMIT ADMIN"*.
- Juri menekan tombol darurat **Emergency Override Lapis 3**, memilih jalur pemenang di pop-up modal, dan menekan *"LOLOSKAN & SEED KE BAGAN"*.
- Database menetapkan pemenang, menutup heat, mengecek rekor BTO baru, dan **secara otomatis menempatkan pemenang ke Bagan Turnamen Babak 2 (Bracket Single Elimination)**.
- **Status:** **PASS**
