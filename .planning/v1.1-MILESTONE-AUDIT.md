## 3. Cross-Phase Integration & End-to-End Flows

### Flow 1: Pendar Emas BTO & Tiket Lolos Babak Kedua (Phase 3 Integration)
- Saat pembalap memenangkan heat dan lolos pemeriksaan Scrutineer juri fisik, data pembalap tercatat dengan finish time.
- Jika waktu mencetak rekor baru turnamen, kartu rekor BTO #1 pada `RealtimeTV.jsx` seketika memancarkan animasi pendar emas berputar (`.gold-shimmer-border`) dengan ikon mahkota `Crown` dan badge `RECORD BTO #1`.
- Pada `ParticipantDashboard.jsx`, tiket babak kedua pemenang menampilkan border pendar emas meriah (`.gold-shimmer-border`) dengan ikon piala `Trophy`.
- **Status:** **PASS**

### Flow 2: Ergonomi Stopwatch 3-Kolom Race Director (Phase 3 Integration)
- Saat 3 mobil berada di starting box, Race Director melihat 3 kartu input sejajar: Jalur A (Pink), Jalur B (Cyan), dan Jalur C (Green).
- Setiap kartu memuat nama pembalap dan tag tim (`[NAMA - TIM]`), memudahkan RD menyalin waktu stopwatch tanpa resiko salah input baris/pembalap.
- Tombol reset kilat (`✕`) dan status DNF / READY terisolasi per jalur.
- **Status:** **PASS**

### Flow 3: Hitungan Mundur Raksasa & Pelepasan Mobil Babak Kedua (Phase 4 Integration)
- Race Director menekan tombol hitungan mundur babak kedua di Dasbor RD.
- Socket event `COUNTDOWN_STARTED` dan `COUNTDOWN_TICK` ditangkap oleh `RaceContext.jsx` dan diumpankan ke `RealtimeTV.jsx`.
- Overlay raksasa `z-50 inset-0` seketika mengambil alih layar TV 16:9 dengan backdrop radial gelap berdenyut crimson, scanlines CRT, bar LED 10-segmen, angka raksasa berdenyut (10 s.d. 1), dan ejaan kata bahasa Indonesia (`SEPULUH`, `SEMBILAN`, dst.).
- Footer overlay menampilkan visual starting grid lengkap dengan pembalap di Jalur A (Pink), B (Cyan), dan C (Green).
- Saat waktu habis, socket event `COUNTDOWN_COMPLETE` meledakkan overlay dengan backdrop neon hijau dan teks *"GO! LEPAS MOBIL! MARSHAL: LEPAS KETIGA MOBIL SEKARANG!"*.
- Jika RD menekan tombol stop darurat, socket event `COUNTDOWN_STOPPED` memunculkan banner cyan *"READY - SIAP LEPAS!"*.
- **Status:** **PASS**
