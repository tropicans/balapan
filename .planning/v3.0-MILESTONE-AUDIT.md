## 3. Key Validations & Invariants

1. **Safety First:** Controlled migrations with reentrant SQLite transactions and timestamped pre-migration DB backups in `data/backups/`.
2. **Deterministic Numbering:** `#1`, `#2`, `#3` sequential participant numbers isolated per active event.
3. **Personal Best BTO:** Continuous replacement of participant lap times, keeping only each racer's single best time.
4. **Fast Winner Registration:** Number-to-name instant preview with automatic slotting into Round 2 heats (A -> B -> C) and one-click undo.
5. **Decoupled Backend:** Users query and canonical state operate cleanly without dependencies on legacy coupon or ticket tables.
6. **No Dead Links:** Deprecated screens gracefully redirect to active dashboards.
7. **Zero Regression:** All 13 test suites pass 100% green (`npm test`), and client production builds cleanly (`npm run build`).
