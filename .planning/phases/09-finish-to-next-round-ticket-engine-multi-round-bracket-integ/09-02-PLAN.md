    - Test 3: Upaya penerbitan tiket baru setelah kualifikasi dikunci ditolak dengan error 400 'Kualifikasi telah dikunci oleh Race Director'.

    1. Di `server/ticketEngine.js`:
       - Tambahkan method `TicketEngine.lockQualifying({ io })`:
         * Update status kualifikasi menjadi `locked` di database.
         * Cek match terakhir di Round 2 jika slot pembalapnya tidak genap 3 (misal hanya 1 atau 2 mobil terisi): biarkan slot kosong sebagai Bye.
         * Emit event WebSocket: `io.emit('qualifying:locked', { is_locked: true, timestamp: new Date().toISOString() })`.
         * Panggil `broadcastFullState()`.
       - Pastikan di method `issueTicket()`, terdapat pengecekan awal status kualifikasi. Jika status `locked`, lemparkan `Error('Kualifikasi telah dikunci oleh Race Director')`.

       - Tambahkan endpoint `GET /api/tickets`:
         * Mengembalikan list tiket `next_round_tickets` diurutkan `ticket_number ASC`, beserta nama pembalap, tim, jalur, dan info bracket.
         * Mengembalikan `stats`: total terbit, total void, total unique racers.
       - Tambahkan endpoint `POST /api/tickets/lock-qualifying`:
         * Memanggil `TicketEngine.lockQualifying({ io })`.
         * Mengembalikan `{ success: true, message: 'Kualifikasi Babak 1 berhasil dikunci. Bagan Babak 2 telah difinalisasi.' }`.
       - Perbarui query `bracketMatches` di `RaceManager.getFullState()` dan `GET /api/bracket/matches` untuk melakukan `LEFT JOIN next_round_tickets` sehingga data `ticket_number_1`, `ticket_index_1`, `ticket_number_2`, `ticket_index_2`, `ticket_number_3`, `ticket_index_3` ikut terkirim ke klien.
    3. Perbarui `server/tests/ticket-engine-flow.test.js` untuk menguji endpoint `/api/tickets`, `/api/tickets/lock-qualifying`, dan penolakan tiket saat kualifikasi locked.
