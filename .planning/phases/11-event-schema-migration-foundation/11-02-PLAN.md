<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → `/api/events` | Untrusted `nama`/`tanggal`/`catatan`/`jumlah_lap` and `:id` path params cross here |
| event service → SQLite | All event SQL is built here and must be parameterised |
| active event → bracket reads | Active-event id decides which rows a read may return |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Tampering | `POST /api/events` fields and `:id` params | mitigate | All SQL uses `db.prepare(...).get/.run/.all(bound)`; ids validated by existence lookup inside the transaction. No string concatenation of request values |
| T-11-05 | Denial of Service | `nama` / `catatan` payloads | mitigate | Service trims and enforces `nama` ≤ 100 and `catatan` ≤ 500 before insert; oversized input returns 400 with an Indonesian message and inserts nothing |
| T-11-06 | Information Disclosure | bracket reads in `getFullState()` / bracket lists | mitigate | Every bracket read filters `WHERE event_id = ?` bound to the active event; test inserts a row on a second event and asserts it is absent from the active event's state |
| T-11-02 | Tampering | backup path | transfer | Handled in plan 11-01 (`server/backup.js`); this plan adds no filesystem path logic |
| T-11-04 | Tampering / Elevation | destructive migration gate | transfer | Handled in plan 11-01 (`runMigrations` gate); this plan performs no migration |
| T-11-SC | Tampering | npm/pip/cargo installs | mitigate | No package installed by this plan |
</threat_model>
