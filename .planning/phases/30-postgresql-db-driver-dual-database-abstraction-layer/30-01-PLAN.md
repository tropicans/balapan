# Phase 30 Plan 01: PostgreSQL DB Driver & Dual-Database Abstraction Layer

**Phase:** 30  
**Milestone:** v4.0 Postgres DB Driver + Redis Socket Adapter & API Rate Limiting  
**Plan:** 30-01-PLAN.md  
**Status:** In Progress  

---

## 1. Goal
Implement a switchable dual-database driver abstraction (`DB_DRIVER=postgres|sqlite`), complete PostgreSQL schema DDL with migration support, ACID transaction handling, and database health check verification.

---

## 2. Requirements & Traceability
- **PG-01**: Abstraksi database driver switchable (`DB_DRIVER=postgres|sqlite`) menggunakan `pg` connection pool & WASM SQLite fallback.
- **PG-02**: Migrasi & seeder skema database lengkap (`events`, `participants`, `matches`, `winners`, `bto`, `users`) ke PostgreSQL.
- **PG-03**: Manajemen transaksi database ACID & penguncian aman pada mutasi saldo/tiket.
- **PG-04**: Endpoint kesehatan database (`/api/health`) dan verifikasi test suite dual-driver.

---

## 3. Tasks & Proposed Changes

### Task 1: Dual-Database Driver Abstraction (`server/db.js` & `server/dbAdapter.js`)
- Install / import `pg` (or handle dynamic import of `pg` client/pool when `DB_DRIVER=postgres`).
- Implement unified database adapter supporting both `sqlite` (sql.js / better-sqlite3 style) and `postgres` (pg pool).
- Implement standard wrapper methods: `prepare(sql)`, `get(...params)`, `all(...params)`, `run(...params)`, `exec(sql)`, `transaction(fn)`.

### Task 2: PostgreSQL DDL & Migration (`server/migrations.js` & `server/schemas/postgres-schema.sql`)
- Create PostgreSQL schema definitions for tables: `events`, `users`, `coupons`, `coupon_packages`, `bto_records`, `marshal_winner_logs`, `next_round_tickets`, `round_locks`, `bracket_matches`, `tournament_settings`.
- Update `server/migrations.js` to run appropriate migrations based on active `DB_DRIVER`.

### Task 3: Health Endpoint Update (`server/index.js`)
- Update `GET /api/health` to include `db_driver` (`postgres` or `sqlite`), connection pool status, and response latency.

### Task 4: Dual-Driver Test Suite (`server/tests/db-driver-abstraction.test.js`)
- Add automated test verifying database adapter interface compliance and transaction behavior.

---

## 4. Verification Plan

### Automated Tests
- Run `node --test server/tests/db-driver-abstraction.test.js` to verify database abstraction layer.
- Run full test suite `npm test`.

### Manual Verification
- Check `/api/health` output for `db_driver` field.
