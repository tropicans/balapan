# Phase 22 Plan 01: Frontend Google Login, Pending Gate & Public Route Bypass

**Phase:** 22  
**Milestone:** v3.2 Google OAuth Authentication & Admin Approval System  
**Plan:** 22-01-PLAN.md  
**Status:** In Progress  

---

## 1. Goal
Implement frontend Google authentication integration, React `AuthContext`, operational route gating, pending approval screen with real-time unlock, public route bypass for `/tv` and `/bracket`, and user profile/logout controls in the Navbar.

---

## 2. Tasks & Proposed Changes

### Task 1: Update `client/index.html`
- Load Google Identity Services SDK `<script src="https://accounts.google.com/gsi/client" async defer></script>`.

### Task 2: Create `client/src/context/AuthContext.jsx`
- Manage `token`, `user`, `loading`, and `error`.
- On mount: read token from `localStorage.getItem('dg_auth_token')`. If present, fetch `/api/auth/me`.
- Connect to Socket.IO (`user:updated` event): if `payload.id === user.id`, update `user` state live.
- Provide:
  - `loginWithGoogleToken(idToken)`: calls `POST /api/auth/google`.
  - `mockLogin(email, name, role)`: dev login helper calling mock payload.
  - `logout()`: calls `POST /api/auth/logout`, clears localStorage token, resets `user` to null.

### Task 3: Create Auth Gate Components
- `client/src/components/auth/LoginScreen.jsx`:
  - Official Google Sign-In button container (GIS initialized via `window.google.accounts.id`).
  - Fallback / Dev sign-in modal for quick local simulation.
  - "Lihat Layar Publik" link button allowing direct jump to `/tv` or `/bracket`.
- `client/src/components/auth/PendingApprovalScreen.jsx`:
  - Shows user name, email, avatar, and badge `MENUNGGU PERSETUJUAN`.
  - Message: "Akun Anda terdaftar dan sedang menunggu persetujuan dari Super Admin (`tropicans@gmail.com`)."
  - Auto-updates on approval via WebSocket.
  - Action buttons: "Lihat Layar TV Sirkuit" and "Logout".
- `client/src/components/auth/SuspendedAccountScreen.jsx`:
  - Notifies user if status is `suspended` or `rejected`.
  - Action: "Logout".

### Task 4: Integrate Auth into `client/src/App.jsx`
- Wrap `AppContent` with `AuthProvider`.
- Define `PUBLIC_SCREENS = ['tv', 'bracket']`.
- If screen is protected:
  - Check `user` state. If unauthenticated -> show `LoginScreen`.
  - If `user.status === 'pending'` -> show `PendingApprovalScreen`.
  - If `user.status === 'suspended'` -> show `SuspendedAccountScreen`.
  - If `user.status === 'approved'` -> show requested dashboard.

### Task 5: Update `client/src/components/ui/Navbar.jsx`
- Display Google operator avatar, name, and role badge (`SUPER ADMIN`, `ADMIN`, `KASIR`, `RACE DIRECTOR`, `SCRUTINEER`, `VIEWER`).
- Show dropdown with user details and "Keluar (Logout)" action.
- If not logged in and on public screen, show subtle "Login Petugas" button.
