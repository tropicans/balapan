# Plan 10-01: End-to-End Tournament Lifecycle Test Suite & Ticket Telemetry Service

<objective>
Membangun test suite integrasi E2E end-to-end (`server/tests/e2e-tournament-lifecycle.test.js`) yang memvalidasi siklus turnamen lengkap dari pendaftaran kasir, kupon fisik 50 kotak, start box marshal, finish balapan, penerbitan tiket digital Babak 2, auto-placement bagan eliminasi, All-3-Same-Lane Auto-Advance, hingga kunci kualifikasi. Serta memperkaya `RaceManager.getFullState()` dengan telemetri tiket (`ticketStats`) agar TV HUD dan seluruh client menerima status kuota real-time.
</objective>

<threat_model>
### Threats & Mitigations
- **T-10-01: Race Condition / Desinkronisasi State pada Uji Siklus Lengkap E2E**
  - *Risk*: Uji alur dari aktivasi kupon, pemotongan kupon di meja finish, hingga penerbitan tiket gagal karena state race atau transaksi database saling tumpang tindih.
  - *Mitigation*: Test suite menggunakan server Express instance ephemeral port dengan database bersih (`temp` in-memory SQLite / fresh test db) dan memvalidasi setiap assertion secara deterministik.
- **T-10-02: Perhitungan Kuota Tiket Babak 2 Meluap / Negatif**
  - *Risk*: Jika tiket diterbitkan melebihi kuota target atau dibatalkan (void), `remaining_quota` bernilai negatif atau salah kalkulasi.
  - *Mitigation*: `TicketEngine.getTicketStats()` secara eksplisit menghitung `target_quota` dari total slot Round 2 (`SELECT COUNT(*) * 3 FROM bracket_matches WHERE round_number = 2` atau fallback `tournament_settings`), dan `remaining_quota = Math.max(0, target_quota - total_issued)`.
</threat_model>

## Task 1: Test Suite E2E Lifecycle Turnamen Lengkap (Wave 0)

<task_instruction>
Buat file test integrasi baru `server/tests/e2e-tournament-lifecycle.test.js`.
Test suite ini menguji secara terprogram alur operasional turnamen end-to-end:
1. **Kasir Activation**: Mendaftarkan pembalap baru (atau mengambil pembalap demo) dan mengaktifkan paket kupon fisik 50 kotak (`POST /api/cashier/packages/activate`).
2. **Marshal Registration & Debit**: Petugas start box memasukkan pembalap ke Jalur A, Jalur B, dan Jalur C (`POST /api/marshal/register-box`) dengan nomor seri kupon dan nomor kotak (1, 2, 3), memotong saldo kupon secara valid.
3. **Finish & Ticket Issuing**: Race Director / Meja Finish mencatat pemenang heat (`POST /api/marshal/record-winner`).
4. **Ticket Auto-Issuance**: Memvalidasi tiket tercatat di `next_round_tickets` dengan status `issued`, sequential number `#1`, dan kode `TKT-B2-001`.
5. **Seeding ke Bagan Round 2**: Memvalidasi tiket ter-seeding ke match Round 2 pertama pada slot Jalur kemenangan yang sesuai.
6. **Multi-Ticket Seeding**: Memasukkan kemenangan kedua untuk pembalap yang sama dan memverifikasi penamaan label `Nama #1`, `Nama #2`.
7. **All-3-Same-Lane Auto-Advance**: Memasukkan tiket ketiga untuk pembalap yang sama mengisi slot ketiga di match Round 2 yang sama, memverifikasi `is_auto_advanced = 1` dan pemenang otomatis maju ke match Round 3 (Grand Final).
8. **Kunci Kualifikasi**: Memanggil `POST /api/tickets/lock-qualifying` dan memastikan kualifikasi berstatus `locked`, Bye system diterapkan bila ada slot ganjil/tidak genap 3, serta percobaan menerbitkan tiket baru setelah lock ditolak dengan error 400.
</task_instruction>

## Task 2: Integrasi Ticket Telemetry ke `RaceManager.getFullState()` & `TicketEngine`

<task_instruction>
Perbarui `server/ticketEngine.js` dan `server/raceManager.js`:
1. Pada `server/ticketEngine.js`:
   - Sempurnakan `getTicketStats()` agar mengembalikan objek terstruktur:
     ```javascript
     {
       total_issued: number,
       total_void: number,
       target_quota: number, // Dihitung dari slot Round 2 atau setting 'qualifying_target_quota' (default: 24 atau 9)
       remaining_quota: number, // Math.max(0, target_quota - total_issued)
       is_locked: boolean,
       is_critical: boolean, // true jika remaining_quota <= 4 dan !is_locked
       racers: Array<{ user_id, user_name, team_name, ticket_count }>,
       tickets: Array<{ id, ticket_number, ticket_code, user_name, team_name, lane, bracket_match_number, created_at }>
     }
     ```
   - Pastikan emit socket `ticket:granted` menyertakan `stats` lengkap yang berisi field di atas.
2. Pada `server/raceManager.js`:
   - Tambahkan `ticketStats: TicketEngine.getTicketStats()` pada payload `getFullState()`.
   - Dengan begitu, setiap kali event `STATE_UPDATE` atau request `GET /api/state` dipanggil, Layar TV Sirkuit dan seluruh klien langsung menerima data kuota tiket dan status lock kualifikasi terkini.
</task_instruction>
