Implement Race Exceptions & Recovery mechanisms:
1. "SEMUA CO / DNF (No Winner)" (EXCP-01) - Emergency race closure when all cars crash/course-out without winner. Coupons remain deducted.
2. "DEKLARASI RE-RACE" (EXCP-02) - Controlled restart permit for selected lanes without deducting new coupons or forcing racers to re-scan.
</objective>

<task type="auto">
  <name>Task 1: Implement Backend Logic for All CO/DNF and Re-Race</name>
  <files>server/raceManager.js, server/index.js</files>
  <action>
    1. In server/raceManager.js:
       - Add `declareAllCO(raceId)`:
         - Verifies race exists and is in 'pre-start' or 'locked' status.
         - Updates race status to 'completed', sets winner_id = NULL.
         - Updates registrations in that race: finish_time = NULL, status = 'dnf_co', scrutineer_status = NULL.
         - Returns { success: true, raceNumber, message: 'Semua mobil Course Out / DNF. Heat ditutup tanpa pemenang.' }.
       - Add `declareReRace(raceId, lanes)`:
         - Takes raceId and array of lanes (e.g., ['A', 'B']).
         - Verifies race exists and is in 'locked' or 'pre-start'.
         - For each lane in `lanes`: updates registration status = 'ready', finish_time = NULL, scrutineer_status = NULL.
         - Sets race status back to 'pre-start'.
         - Ensures NO coupon deduction happens (re-race free permit).
         - Returns { success: true, raceNumber, lanes, message: `Balap ulang dideklarasikan untuk Jalur ${lanes.join(', ')}` }.
    2. In server/index.js:
       - Add POST `/api/race/all-co`: calls `RaceManager.declareAllCO(raceId)`, emits `RACE_ALL_CO` event, broadcasts full state.
       - Add POST `/api/race/re-race`: calls `RaceManager.declareReRace(raceId, lanes)`, emits `RACE_RERACE_DECLARED` event, broadcasts full state.
  </action>
  <verify>Run node server/tests/race-flow.test.js</verify>
  <done>Backend methods and endpoints respond with correct status and atomic transactions</done>
</task>
