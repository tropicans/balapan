## Visuals & Layout Hierarchy

- **Primary Screen Layout:** 2-column split viewport on `/cashier` (`CashierDashboard.jsx`).
  - **Left Column (40% width):** Quick Registration Panel with autofocus on Serial Number input (`#ffaa00` glow outline).
  - **Right Column (60% width):** Live Feed & Quota Monitoring Panel with search bar, filter chips, and scrollable package card feed.
- **Focal Point:** Left column Serial Number input field (`autoFocus`, neonAmber glow), drawing cashier eyes immediately upon tab switch.
- **Secondary Anchor:** Right column real-time quota gauge (`42 / 50 Kotak`) with color-coded depletion progress.
- **Accessibility:** All icon-only buttons include descriptive `title` and `aria-label` attributes.
