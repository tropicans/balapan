# Plan 10-02: Realtime Circuit TV Ticket HUD Showcase & Operational Navigation Polish

<objective>
Menghadirkan pengalaman siaran TV Sirkuit 16:9 (`RealtimeTV.jsx`) yang spektakuler dengan:
1. Widget kuota tiket Babak 2 di header HUD dengan efek denyut merah saat sisa tiket kritis (<= 4 tiket).
2. Banner penutupan kualifikasi saat kualifikasi dikunci oleh Race Director.
3. Running ticker strip pemegang tiket Babak 2 di footer TV dengan animasi marquee horizontal mulus.
4. Modal overlay perayaan "NEW QUALIFIER!" holografik emas dengan audio synthesizer kemenangan Web Audio (`playTicketChime`) dan auto-dismiss 6-8 detik.
5. Perampingan navigasi Navbar (`Navbar.jsx`) agar murni berfokus pada alur operasional perlombaan sirkuit.
</objective>

<threat_model>
### Threats & Mitigations
- **T-10-03: Layout Shift / Jitter pada Layar TV 16:9 saat Ticker Berputar**
  - *Risk*: Ticker horizontal di bagian footer menyebabkan layout bergeser atau tersendat (clipping jitter) saat tiket bertambah.
  - *Mitigation*: Menggunakan CSS keyframe transform `translate3d(0, 0, 0)` dengan track terisolasi `overflow-hidden flex-nowrap` dan duplikasi item ticker saat jumlah item sedikit (zero-one-many contract) agar looping terjadi mulus tanpa patahan.
- **T-10-04: Audio Context Autoplay Blocking pada Pop-up Showcase Modal**
  - *Risk*: Browser memblokir Web Audio saat event socket tiba jika pengguna belum pernah berinteraksi dengan layar TV.
  - *Mitigation*: Menggunakan helper `sound.playTicketChime()` yang aman dengan graceful catch (`audioCtx.state === 'suspended' ? audioCtx.resume() : null`) serta tombol interaktif manual [ESC] / Tutup jika modal dibuka.
</threat_model>

## Task 2: Running Ticker Strip Pemegang Tiket Babak 2 di Footer TV (`RealtimeTV.jsx`)

<task_instruction>
Perbarui footer `RealtimeTV.jsx` untuk menyiarkan antrean pemegang tiket Babak 2 (E1):
1. **Daftar Tiket Terbit**:
   - Ambil daftar tiket dari `raceState.ticketStats?.tickets` (atau array tiket aktif).
   - Format setiap item ticker: `#X [KODE_TIKET] NAMA_PEMBALAP [TIM] (HH:MM)` misal:
     `#1 TKT-B2-001 BUDI SANTOSO [GTR] ••• #2 TKT-B2-002 ANDI PRATAMA [RRT]`
   - Terapkan badge kontras emas-hitam cyberpunk (`bg-neonAmber/20 border border-neonAmber text-neonAmber font-mono px-2 py-0.5 clip-cyber`).
2. **Handling State Khusus**:
   - **Empty State**: Jika belum ada tiket yang terbit, tampilkan teks marquee:
     `BELUM ADA PEMEGANG TIKET BABAK 2 • KUALIFIKASI SEDANG BERLANGSUNG`
   - **Zero-One-Many**: Gandakan deretan elemen jika jumlah tiket <= 2 agar rotasi animasi continuous marquee tidak menyisakan ruang kosong di layar 16:9.
</task_instruction>

## Task 3: Modal Pop-up Holografik Emas "NEW QUALIFIER!" Showcase & Audio Chime

<task_instruction>
