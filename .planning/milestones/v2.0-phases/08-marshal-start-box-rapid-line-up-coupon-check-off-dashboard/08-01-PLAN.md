<task type="auto" tdd="true">
  <name>Task 2: REST API Pencatatan Pemenang Babak 1, Debit Kuota Atomic, Validasi Kupon, dan Pembatalan 60s</name>
  <files>server/index.js, server/tests/marshal-flow.test.js</files>
  <read_first>server/index.js, server/db.js, server/raceManager.js, server/tests/marshal-flow.test.js</read_first>
  <threat_model>
    <threat>T-08-02: Race condition saat debit kupon, pembatalan ganda (replay undo), atau pembatalan di luar batas waktu 60 detik.</threat>
    <mitigation>Eksekusi debit dan revert di dalam db.transaction(), validasi status paket kupon, dan enforce batasan waktu selisih timestamp <= 60 detik di server.</mitigation>
  </threat_model>
  <behavior>
    - Test 1: POST /api/marshal/record-winner dengan nomor seri yang belum terdaftar di kasir mengembalikan status 404 KUPON BELUM TERDAFTAR DI KASIR (per D-10).
    - Test 2: POST /api/marshal/record-winner dengan nomor seri valid mendebit used_quota (+1), mengurangi remaining_quota (-1), mencatat log pemenang, dan memanggil RaceManager.seedIntoBracket() (per D-05, D-06).
    - Test 3: POST /api/marshal/record-winner menolak kupon yang remaining_quota <= 0 atau berstatus 'void'.
    - Test 4: POST /api/marshal/undo-last-winner dalam batas 60 detik berhasil mengembalikan kuota kupon, mengubah status log menjadi 'undone', dan menyiarkan event WebSocket (per D-09).
    - Test 5: POST /api/marshal/undo-last-winner setelah lebih dari 60 detik ditolak dengan status 400 'Koreksi Kedaluwarsa (>60s)'.
  </behavior>
  <action>
    1. Di `server/index.js`, tambahkan endpoint `POST /api/marshal/record-winner`:
       - Parameter body: `{ serial_number, lane }`. Validasi `lane` harus salah satu dari 'A', 'B', 'C'.
       - Cari paket kupon aktif di `coupon_packages`: `SELECT * FROM coupon_packages WHERE UPPER(TRIM(serial_number)) = UPPER(TRIM(?))`.
       - Jika tidak ditemukan: return `404` dengan `{ success: false, error: 'KUPON BELUM TERDAFTAR DI KASIR', code: 'COUPON_NOT_FOUND' }`.
       - Jika `pkg.status === 'void'` atau `pkg.remaining_quota <= 0`: return `400` dengan `{ success: false, error: 'Kuota Kupon Telah Habis atau Lembar Void' }`.
       - Jalankan transaksi atomik `db.transaction()`:
         * Update `coupon_packages`: `used_quota = used_quota + 1`, `remaining_quota = remaining_quota - 1`, jika `remaining_quota - 1 === 0` set `status = 'completed'`.
         * Sinkronkan saldo `coupons`: `UPDATE coupons SET balance = MAX(0, balance - 1) WHERE user_id = ?`.
         * Insert record baru ke `marshal_winner_logs` dengan `box_number = used_quota + 1`.
         * Masukkan pemenang ke slot Babak 2 via `RaceManager.seedIntoBracket(pkg.user_id)`.
       - Siarkan WebSocket event: `io.emit('marshal:winner-recorded', { winner: {...}, timestamp: new Date() })` dan panggil `broadcastFullState()`.
       - Return `200` dengan data lengkap pemenang (racer name, team name, box number, remaining quota, log_id).
    2. Tambahkan endpoint `POST /api/marshal/undo-last-winner`:
       - Parameter body: `{ log_id }` opsional. Jika tidak ada `log_id`, ambil record `marshal_winner_logs` terakhir dengan `status = 'active'`.
       - Hitung selisih waktu `(Date.now() - new Date(log.created_at).getTime()) / 1000`. Jika `> 60`, return `400` dengan `{ success: false, error: 'Koreksi Kedaluwarsa (>60s)' }`.
       - Jalankan transaksi atomik:
         * Update `coupon_packages`: `used_quota = used_quota - 1`, `remaining_quota = remaining_quota + 1`, set `status = 'active'`.
         * Sinkronkan `coupons`: `UPDATE coupons SET balance = balance + 1 WHERE user_id = ?`.
         * Update `marshal_winner_logs`: set `status = 'undone'`.
       - Siarkan WebSocket event `io.emit('marshal:winner-undone', { log_id: log.id })` dan `broadcastFullState()`.
       - Return `200` dengan `{ success: true, message: 'Pemenang heat berhasil dibatalkan dan kuota kupon dikembalikan', data: { log_id, serial_number, remaining_quota } }`.
    3. Tambahkan endpoint `GET /api/marshal/recent-winners`:
       - Mengembalikan 3-5 catatan pemenang terakhir dari `marshal_winner_logs` untuk ringkasan di dashboard.
    4. Perbarui test suite di `server/tests/marshal-flow.test.js` untuk menguji semua skenario endpoint di atas.
  </action>
