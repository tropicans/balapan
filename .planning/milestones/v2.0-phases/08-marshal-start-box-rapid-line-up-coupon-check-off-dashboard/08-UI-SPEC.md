## Visuals & Layout Hierarchy

- **Primary Screen Layout:** Tablet-first touch HUD layout on `/marshal` (`MarshalDashboard.jsx`).
  - **Top Bar:** Header turnamen, mode switcher ("Babak 1: Kualifikasi" vs "Babak 2: Eliminasi Bracket"), status konektivitas WebSocket real-time, dan jam sirkuit.
  - **Babak 1 Main View (Pencatatan Cepat Meja Finish):**
    - **Top Row (Lane Selector):** 3 Tombol Jalur Raksasa (Jalur A Pink `#ff007f`, Jalur B Cyan `#00f0ff`, Jalur C Green `#00ff66`) dengan tinggi minimum 72px agar mudah ditekan jari marshal finish.
    - **Middle Section (Numpad & Serial Display):**
      - Display Nomor Seri Kupon Fisik (`012` atau `CPN-001`) berukuran teks besar `font-orbitron text-2xl` dengan frame chamfer cyberpunk.
      - On-Screen Numpad Sentuh berukuran tombol minimal 64px x 64px (angka 0-9, Clear `C`, Backspace `⌫`, dan tombol konfirmasi "Catat Pemenang Heat").
    - **Bottom Action / Notification Bar:** Banner notifikasi pemenang terakhir yang berhasil dicatat disertai tombol Undo "Batalkan Kemenangan Terakhir" dengan visual progress timer mundur 60 detik.
  - **Babak 2 Main View (Eksekusi Bracket Eliminasi):**
    - Kartu pertandingan aktif (`bracket_matches`) yang menampilkan 3 pembalap yang dijadwalkan di Jalur A, Jalur B, dan Jalur C.
    - 1-Tap Seleksi Pemenang langsung pada nama pembalap untuk meloloskannya ke putaran bracket selanjutnya.
- **Focal Point:** Display Nomor Seri Kupon dan Tombol Jalur Terpilih di Babak 1, memfokuskan mata juri finish langsung ke angka seri yang dibawa pembalap.
- **Secondary Anchor:** Tombol "Catat Pemenang Heat" dengan aksen `#ffaa00` dan banner status verifikasi instan pemenang.
- **Accessibility:** Semua tombol kontrol sentuh dan icon-only actions memiliki atribut `aria-label` dan teks fallback untuk pembaca layar.
