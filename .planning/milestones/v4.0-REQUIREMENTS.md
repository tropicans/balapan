# Milestone v4.0 Requirements: Postgres DB Driver + Redis Socket Adapter & API Rate Limiting (Standalone Decoupled)

## Requirements

### 1. PostgreSQL DB Driver (`PG`)
- [x] **PG-01**: Abstraksi database driver switchable (`DB_DRIVER=postgres|sqlite`) menggunakan `pg` connection pool & WASM SQLite fallback.
- [x] **PG-02**: Migrasi & seeder skema database lengkap (`events`, `participants`, `matches`, `winners`, `bto`, `users`) ke PostgreSQL.
- [x] **PG-03**: Manajemen transaksi database ACID & penguncian aman (pessimistic/optimistic lock) pada mutasi saldo/tiket.
- [x] **PG-04**: Endpoint kesehatan database (`/api/health`) dan verifikasi test suite dual-driver (PostgreSQL & SQLite).

### 2. Redis Socket Adapter (`REDIS`)
- [x] **REDIS-01**: Integrasi `@socket.io/redis-adapter` dengan `ioredis` client pada Express WebSocket server.
- [x] **REDIS-02**: Auto-fallback ke in-memory Socket.IO adapter saat `REDIS_URL` tidak dikonfigurasi / mode offline venue.
- [x] **REDIS-03**: Sinkronisasi event real-time (Pub/Sub) lintas node/instance server untuk multi-container cluster.

### 3. API Rate Limiting (`RATELIM`)
- [x] **RATELIM-01**: Middleware Rate Limiting terpasang pada endpoint sensitif (`/api/auth/*`, `/api/participants/*`, `/api/winners/*`, `/api/bracket/*`).
- [x] **RATELIM-02**: Redis store rate limiter dengan fallback in-memory store untuk proteksi abuse & DDoS.
- [x] **RATELIM-03**: Respon HTTP 429 Too Many Requests & header RateLimit standar yang konsisten.

### 4. Decoupled Standalone System (`STANDALONE`)
- [x] **STANDALONE-01**: Pelepasan total ketergantungan turnamen dari Google Sheets (seluruh pendaftaran & data peserta dikelola murni via DB lokal/Postgres).
- [x] **STANDALONE-02**: Modul Impor & Ekspor CSV/JSON lokal di Kasir (`/cashier`) & Admin (`/admin`) sebagai pengganti Google Sheets sync.
- [x] **STANDALONE-03**: Google OAuth 2.0 Auth tetap dipertahankan sebagai metode login utama (dengan Emergency Offline Login sebagai backup venue).
- [x] **STANDALONE-04**: Verifikasi operasional turnamen murni mandiri tanpa dependensi pada Google Sheets.
