# Phase 31 Plan 01: Redis Socket Adapter & API Rate Limiting Infrastructure

**Phase:** 31  
**Milestone:** v4.0 Postgres DB Driver + Redis Socket Adapter & API Rate Limiting  
**Plan:** 31-01-PLAN.md  
**Status:** In Progress  

---

## 1. Goal
Integrate Redis Socket.IO adapter (`@socket.io/redis-adapter`) with auto-fallback for horizontal WebSocket scaling and build an API Rate Limiting middleware protecting sensitive endpoints (`/api/auth/*`, `/api/participants/*`, `/api/winners/*`, `/api/bracket/*`).

---

## 2. Requirements & Traceability
- **REDIS-01**: Integrasi `@socket.io/redis-adapter` dengan `ioredis` client pada Express WebSocket server.
- **REDIS-02**: Auto-fallback ke in-memory Socket.IO adapter saat `REDIS_URL` tidak dikonfigurasi / mode offline venue.
- **REDIS-03**: Sinkronisasi event real-time (Pub/Sub) lintas node/instance server.
- **RATELIM-01**: Middleware Rate Limiting terpasang pada endpoint sensitif.
- **RATELIM-02**: Redis store rate limiter dengan fallback in-memory store.
- **RATELIM-03**: Respon HTTP 429 Too Many Requests & header RateLimit standar.

---

## 3. Tasks & Proposed Changes

### Task 1: Redis Socket.IO Adapter (`server/index.js` & `server/redisAdapter.js`)
- Create Redis connection helper `server/redisAdapter.js` using `ioredis` and `@socket.io/redis-adapter`.
- Handle graceful fallback to in-memory adapter if `REDIS_URL` is absent or connection fails.
- Attach adapter to Socket.IO server `io`.

### Task 2: API Rate Limiting Middleware (`server/middleware/rateLimiter.js`)
- Implement rate limiting middleware supporting sliding window count per client IP.
- Use Redis store if `REDIS_URL` is present; fallback to in-memory Map store.
- Apply middleware to endpoints: `/api/auth/*`, `/api/participants/*`, `/api/winners/*`, `/api/bracket/*`.
- Set standard rate limit headers: `RateLimit-Limit`, `RateLimit-Remaining`, `Retry-After`.

### Task 3: Automated Test Suite (`server/tests/redis-ratelimit.test.js`)
- Add test suite verifying rate limiting 429 responses, rate limit headers, and fallback behavior.
