# Phase 29 Plan 01: Standalone Decoupled System & Local CSV/JSON Import/Export

**Phase:** 29  
**Milestone:** v4.0 Postgres DB Driver + Redis Socket Adapter & API Rate Limiting  
**Plan:** 29-01-PLAN.md  
**Status:** In Progress  

---

## 1. Goal
Decouple the tournament system completely from mandatory Google Sheets sync. Provide standalone local CSV/JSON import and export REST endpoints for Participants, BTO, and Winners, integrated into the Kasir (`/cashier`) and Admin (`/admin`) web dashboards, while preserving Google OAuth 2.0 and Emergency Offline Login.

---

## 2. Requirements & Traceability
- **STANDALONE-01**: Pelepasan total ketergantungan turnamen dari Google Sheets (seluruh pendaftaran & data peserta dikelola murni via DB lokal).
- **STANDALONE-02**: Modul Impor & Ekspor CSV/JSON lokal di Kasir (`/cashier`) & Admin (`/admin`).
- **STANDALONE-03**: Google OAuth 2.0 Auth tetap dipertahankan (dengan Emergency Offline Login sebagai backup venue).
- **STANDALONE-04**: Verifikasi operasional turnamen murni mandiri tanpa dependensi pada Google Sheets.

---

## 3. Tasks & Proposed Changes

### Task 1: Server Endpoints for CSV & JSON Import/Export (`server/index.js`)
- Add `GET /api/participants/export` (supports `format=csv` and `format=json`).
- Add `POST /api/participants/import` (supports JSON array or CSV text body, parses using `parseParticipantCsv`, validates, and executes batch upsert/insert).
- Add `GET /api/bto/export` (exports BTO leaderboard records as CSV/JSON).
- Add `POST /api/bto/import` (batch imports BTO records with validation).
- Add `GET /api/winners/export` (exports registered winners list as CSV/JSON).

### Task 2: Decouple Google Sheets Sync Dependency (`server/services/googleSheetService.js` & `server/index.js`)
- Ensure that system operates 100% smoothly when `GOOGLE_SHEET_ID` or Google Sheets URLs are absent or blank.
- Make all Google Sheets sync functions return clean fallback responses without throwing unhandled network exceptions or hanging server startup when internet is unavailable.

### Task 3: UI Integration for Import/Export in Admin & Kasir (`client/src/pages/AdminDashboard.jsx` & `client/src/pages/CashierPage.jsx`)
- Add "Export Data (CSV / JSON)" and "Import Data" UI controls in Admin Dashboard under Participant Management.
- Add "Export Data Peserta & Transaksi" button in Kasir page.
- Add file upload & drag-and-drop modal for CSV/JSON import with live preview, error logging per invalid line, and success summary.

### Task 4: Verify Google OAuth & Emergency Offline Login
- Ensure `POST /api/auth/google` continues to function for online authentication.
- Ensure `/api/auth/me` and emergency offline auth mode allow full offline venue functionality.
