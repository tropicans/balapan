## 1. Executive Summary

Milestone v2.0 sukses mengintegrasikan alur operasional fisik sirkuit Mini 4WD Tamiya berbasis lembar kupon pre-printed dan peranan Marshal di Start Box dengan ekosistem digital turnamen real-time:

1. **Pre-Printed Coupon Package Registration & Cashier Flow (Phase 07)**:
   - Registrasi paket kupon kilat via Kasir (`/cashier`), mendukung input barcode/serial kertas fisik pre-printed dengan debit kuota atomic (50 kotak per lembar).
   - Validasi ketat anti-duplikasi serial sheet, pelacakan sisa kuota, dan pencarian instan nama/tim/barcode.

2. **Marshal Start Box Rapid Line-Up & Coupon Check-Off Dashboard (Phase 08)**:
   - Antarmuka khusus Start Box (`/marshal`) tablet-optimized dengan tombol sentuh jempol ber-target 64px+ dan panduan visual box.
   - Penataan cepat 3 kontestan pada Jalur A (Pink), Jalur B (Cyan), dan Jalur C (Green) dengan panduan nomor kotak yang harus dicoret (misal `"CORET KOTAK #9"`).
   - Sinkronisasi instan via WebSocket broadcast ke Dasbor Race Director (`/race-director`).

3. **Finish-to-Next-Round Ticket Engine & Multi-Round Bracket Integration (Phase 09)**:
   - Integrasi langsung finish race dengan penerbitan tiket Babak Berikutnya (`next_round_tickets`) secara atomic.
   - Pemenang tiket otomatis di-seed ke slot kosong Babak 2 pada bracket 3-jalur tanpa risiko over-capacity.
   - Penanganan status Klontang/CO (DNF) yang menghanguskan kupon tanpa penerbitan tiket baru.

4. **Realtime Circuit TV Ticket HUD Showcase & Polish (Phase 10)**:
   - Display Layar TV Sirkuit 16:9 (`/tv`) dilengkapi ticker running real-time menyiarkan pembalap yang baru saja mengamankan tiket Babak 2.
   - Widget HUD kuota tiket real-time dengan neon progress ring/bar yang menghitung sisa tiket yang diperebutkan di arena.
   - Pengujian siklus turnamen end-to-end terverifikasi 100% pass across all test suites.

## 3. Cross-Phase Integration & End-to-End Flows

### Flow 1: Kasir $\rightarrow$ Marshal Line-Up (Phase 07 to Phase 08)
- Kasir mendaftarkan nomor seri paket lembar kupon fisik peserta di `/cashier`.
- Marshal di Start Box (`/marshal`) langsung dapat mencari nama peserta atau memindai barcode lembar kupon tersebut.
- Data kuota dan kepemilikan terverifikasi atomic secara real-time.
- **Status:** **PASS** (Teruji di `coupon-package.test.js` dan `marshal-flow.test.js`).

### Flow 2: Marshal Start Box $\rightarrow$ Race Director (Phase 08 to Phase 09)
- Marshal mengisi 3 peserta di Jalur A (Pink), B (Cyan), dan C (Green), lalu mencoret kotak kupon fisik sesuai instruksi UI ("CORET KOTAK #X").
- Konfirmasi debit atomic 1 kupon per peserta.
- WebSocket mem-broadcast antrean mobil siap ke Dasbor Race Director (`/race-director`).
- **Status:** **PASS** (Teruji di `marshal-flow.test.js` dan `race-flow.test.js`).

### Flow 3: Race Director FINISH / CO $\rightarrow$ Ticket Engine & Bracket Seeding (Phase 09)
- Race Director mengonfirmasi hasil heat:
  - Peserta yang FINISH otomatis diterbitkan tiket `TKT-B2-XXX` via `issueNextRoundTicket` dan di-seed ke slot kosong Babak 2 bracket 3-jalur.
  - Peserta yang Klontang / CO (DNF) tidak memperoleh tiket, namun kupon yang didebit Marshal tetap hangus.
- **Status:** **PASS** (Teruji di `ticket-engine-flow.test.js` dan `bracket-3lane.test.js`).

### Flow 4: Ticket Issue $\rightarrow$ Circuit TV HUD Running Ticker & Quota (Phase 10)
- Event penerbitan tiket dan status turnamen di-broadcast ke Layar TV Sirkuit (`/tv`).
- Running ticker menyiarkan pembalap yang baru lolos tiket Babak 2 secara real-time.
- Neon progress widget memperbarui sisa kuota tiket Babak 2 seketika.
- **Status:** **PASS** (Teruji di `e2e-tournament-lifecycle.test.js` dan Vite client production build).
