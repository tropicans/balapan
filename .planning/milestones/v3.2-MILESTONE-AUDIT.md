- Official Google OAuth 2.0 / Google Identity Services integration.
- Root Super Admin auto-provisioning for `tropicans@gmail.com` with immunity safeguards.

## 4. Cross-Phase Integration & E2E Verification

1. **Authentication Handshake & Token Lifecycle**:
   - Google ID token verified in `authService.verifyGoogleToken` -> user provisioned -> session UUID stored in `auth_sessions` -> returned to frontend -> stored in `localStorage` -> authenticated requests include `Authorization: Bearer <token>`.
2. **Approval Gate to Active Operator Transition**:
   - Operator signs in with Google -> status `pending` -> rendered `PendingApprovalScreen`.
   - Super Admin opens `/admin` -> clicks "SETUJUI" -> selects role `cashier` -> server updates DB and emits `user:updated`.
   - Operator screen immediately detects socket event, updates state, and renders `/cashier` dashboard without page reload.
3. **Public Route Immunity**:
   - Accessing `/tv` and `/bracket` never displays login or pending gates, enabling live arena broadcasting.
