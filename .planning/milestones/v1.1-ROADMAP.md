# Milestone v1.1: UI/UX & Arena Visual Showcase Polish

**Status:** ✅ SHIPPED 2026-09-03  
**Phases:** 3-4  
**Total Plans:** 2  

## Overview

Menerapkan seluruh rekomendasi hasil audit mendalam sistem UI Designer untuk menyempurnakan ergonomi antarmuka Pusat Komando Race Director serta memberikan pengalaman visual sirkuit bertaraf *showcase* arcade modern.

## Phases

### Phase 3: Race Director 3-Column Ergonomics & BTO Shimmer

**Goal**: Race Director dapat menginput waktu stopwatch fisik 3-jalur secara cepat dan bebas salah baris, serta pemegang rekor BTO #1 mendapatkan elevasi visual pendar emas di TV HUD dan mobile.  
**Depends on**: Milestone v1.0  
**Requirements**: UI-01, UI-02  
**Plans**: 1 plan  

Plans:
- [x] 03-01: Implementasi layout 3-kolom finish time di RD Dashboard & border shimmer BTO emas di TV/Mobile

**Details:**
- Panel input finish time di Dasbor RD tersusun dalam 3 kolom horizontal berdampingan (Jalur A Pink, Jalur B Cyan, Jalur C Green) lengkap dengan nama dan tag pembalap di tiap kartu.
- Kartu BTO #1 pada leaderboard TV HUD memancarkan animasi pendar emas berputar (*cyber golden shimmer border*) untuk menegaskan rekor tercepat.
- Kartu tiket lolos babak kedua pada dashboard pembalap memiliki pendar emas eksklusif.

### Phase 4: Fullscreen Dynamic Countdown HUD Overlay

**Goal**: Layar TV Sirkuit 16:9 menampilkan visual hitungan mundur raksasa yang menyatu dengan audio suara manusia saat 10 detik menuju start.  
**Depends on**: Phase 3  
**Requirements**: UI-03  
**Plans**: 1 plan  

Plans:
- [x] 04-01: Implementasi fullscreen dynamic countdown overlay pada RealtimeTV.jsx

**Details:**
- Saat RD memulai hitungan mundur babak kedua, TV HUD memunculkan overlay dramatis dengan angka raksasa berdenyut (10 s.d. 1) di tengah layar.
- Menggunakan CRT scanlines, backdrop radial berdenyut crimson, ejaan fonetik bahasa Indonesia (`SEPULUH`, `SEMBILAN`, dst.), serta 10-segmen cyber LED bar.
- Saat countdown selesai, overlay meledak dengan animasi teks "GO! LEPAS MOBIL! MARSHAL: LEPAS KETIGA MOBIL SEKARANG!" berlatar pendar neon hijau.
- Menangani event `COUNTDOWN_STOPPED` dengan banner cyan "READY - SIAP LEPAS!" jika dihentikan juri lebih awal.

## Milestone Summary

**Key Decisions:**
- *Ergonomi 3-Kolom Stopwatch*: Mengganti field vertikal satu warna dengan matriks horizontal 3 warna trek (Pink, Cyan, Green) berdampingan untuk menyamai tata letak 3 stopwatch fisik di meja Race Director.
- *Cyber Golden Shimmer*: Menggunakan animasi CSS `@keyframes gold-pulse` dengan pendar hangat untuk membedakan rekor puncak BTO #1 dari kartu pembalap reguler.
- *Fullscreen Countdown Overlay*: Memanfaatkan arsitektur overlay modal fixed `z-50 inset-0` di `RealtimeTV.jsx` yang sinkron real-time via WebSocket events (`COUNTDOWN_STARTED`, `COUNTDOWN_TICK`, `COUNTDOWN_COMPLETE`, `COUNTDOWN_STOPPED`).
