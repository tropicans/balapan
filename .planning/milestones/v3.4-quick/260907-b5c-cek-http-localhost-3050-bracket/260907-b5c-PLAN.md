# Quick Task 260907-b5c: Fix ReferenceError cfg is not defined in BracketDashboard

**Description:** Fix `ReferenceError: cfg is not defined` when rendering `/bracket` in `BracketDashboard.jsx`.

## Root Cause
In `client/src/screens/BracketDashboard.jsx`, inside `renderContestantRow`, `laneConfigs` was defined for lanes A, B, and C, but `const cfg = laneConfigs[lane] || laneConfigs.A;` was omitted. When matches were loaded or rendered, calling `renderContestantRow` triggered `ReferenceError: cfg is not defined`.

## Plan
1. [x] Write reproduction test `server/tests/bracket-dashboard-render.test.js` proving the failure.
2. [x] Add missing `const cfg = laneConfigs[lane] || laneConfigs.A;` in `client/src/screens/BracketDashboard.jsx`.
3. [x] Verify test passes and add to `package.json` test suite.
4. [x] Rebuild Docker container with updated assets.
