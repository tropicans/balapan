# Requirements: NEO-TAMIYA Racing System (Milestone v3.3)

**Defined:** 2026-09-18  
**Milestone:** v3.3 Google Sheets Racer Sync & Admin Integration  
**Core Value:** Operasional turnamen balap Mini 4WD Tamiya yang cepat, adil, bebas antrean, dan nol biaya hardware tambahan melalui alur digital real-time terintegrasi.

## v3.3 Requirements

### Backend Google Sheets Fetch & Parsing

- [x] **SYNC-01**: Service backend dapat mengonversi Google Sheets document URL menjadi format CSV export endpoint (`https://docs.google.com/spreadsheets/d/{id}/export?format=csv&gid={gid}`).
- [x] **SYNC-02**: Service backend melakukan HTTP fetch terhadap export URL Google Sheets dan mem-parsing data racer menggunakan `parseParticipantCsv` (mendukung filter status Lunas / comp Presale & OTS).

### Idempotent Sync Logic & Scoped Allocation

- [x] **SYNC-03**: Sinkronisasi cerdas anti-duplikat: memeriksa daftar nama pembalap yang sudah terdaftar di event aktif (`event_id`), melewati pembalap yang sudah ada, dan hanya meng-insert pembalap baru.
- [x] **SYNC-04**: Pembalap baru dialokasikan `participant_number` secara berurutan melanjutkan nomor urut tertinggi (`MAX(participant_number) + 1`) pada event aktif secara atomik di dalam database transaction.
- [x] **SYNC-05**: Backend menyimpan URL Google Sheet terakhir di tabel `tournament_settings` (key: `google_sheet_sync_url`) dan mengembalikan ringkasan hasil sync (`{ totalFound, addedCount, skippedCount, addedList, skippedList }`).

### API Endpoint & Realtime Notification

- [x] **SYNC-06**: Endpoint `POST /api/participants/sync-sheet` yang diproteksi RBAC (hanya dapat diakses oleh role `admin` atau `cashier`), menerima opsional `sheet_url` atau fallback ke default URL.
- [x] **SYNC-07**: Backend memicu event Socket.IO `participants_imported` dan `STATE_UPDATE` setelah sinkronisasi berhasil agar seluruh layar operator dan kasir langsung tersinkronkan.

### Frontend Cashier & Admin Integration

- [x] **SYNC-08**: Kasir Dasbor (`CashierDashboard.jsx`) memiliki tombol "SYNC GOOGLE SHEET" dengan status loading dan modal konfirmasi yang menampilkan URL target, jumlah baru vs duplikat yang dilewati, serta pesan toast hasil.
- [x] **SYNC-09**: Dasbor Admin (`AdminUserDashboard.jsx`) memiliki tombol dan visual status Sync Google Sheet di Panel Admin (`AdminUserDashboard.jsx`).
- [x] **SYNC-10**: Modal/dialog input cepat memungkinkan admin mengubah atau mengecek URL Google Sheet yang sedang aktif disinkronkan.

## Future Requirements (v4.0+)

- **SYNC-AUTO-01**: Background polling terjadwal otomatis (cron sync setiap X menit) untuk mendeteksi penambahan pendaftar baru tanpa klik manual.
- **SYNC-WEBHOOK-01**: Google Apps Script Webhook trigger yang memanggil backend DGDash secara otomatis setiap kali ada form registrasi masuk.

## Out of Scope

| Feature | Reason |
|---------|--------|
| Penulisan balik (two-way sync / writeback) status ke Google Sheets | Sistem DGDash bersifat consumer data (read-only dari Google Sheets) demi keamanan sheet pendaftaran |
| Otomatisasi pendaftaran kupon/pembayaran di Google Sheets | Pengelolaan keuangan kupon dilakukan panitia di lembar sheet fisik dan sistem kasir internal |
