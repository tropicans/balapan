    In `server/raceManager.js`:
    1. Implement helper methods on `RaceManager`:
       - `static getRoundStatus(round = 2)`:
         Query `SELECT value FROM tournament_settings WHERE key = 'round' || ? || '_status'` (e.g. `round2_status`). Return value || 'open'.
       - `static getRoundProgress(round = 2)`:
         Resolve active event ID via `getActiveEventId()`.
         Query `SELECT COUNT(*) as total, SUM(CASE WHEN status = 'completed' THEN 1 ELSE 0 END) as completed FROM bracket_matches WHERE round_number = ? AND (event_id = ? OR (? IS NULL AND event_id IS NULL))`.
         Compute:
           `total_heats = total || 0`
           `completed_heats = completed || 0`
           `pending_heats = total_heats - completed_heats`
           `is_locked = this.getRoundStatus(round) === 'locked'`
           `can_finalize = total_heats > 0 && pending_heats === 0 && !is_locked`
         Return `{ round, is_locked, total_heats, completed_heats, pending_heats, can_finalize }`.
       - `static lockRound(round = 2)`:
         Get progress via `this.getRoundProgress(round)`.
         If `progress.total_heats === 0`: throw new Error(`Tidak ada heat di Babak ${round} untuk dikunci.`);
         If `progress.pending_heats > 0`: throw new Error(`Masih ada ${progress.pending_heats} heat Babak ${round} yang belum selesai.`);
         Upsert `round${round}_status` = `'locked'` in `tournament_settings` with `CURRENT_TIMESTAMP`.
         Return `this.getRoundProgress(round)`.
       - `static unlockRound(round = 2)`:
         Upsert `round${round}_status` = `'open'` in `tournament_settings` with `CURRENT_TIMESTAMP`.
         Return `this.getRoundProgress(round)`.

  <action>
    In `server/index.js`:
    1. Add route `POST /api/bracket/lock-round`:
       ```javascript
       app.post('/api/bracket/lock-round', async (req, res) => {
         try {
           const round = parseInt(req.body?.round) || 2;
           const result = RaceManager.lockRound(round);
           io.emit(`round${round}:locked`, { round, timestamp: new Date().toISOString() });
           io.emit('bracket_updated');
           broadcastFullState();
           res.json({ success: true, data: result, message: `Babak ${round} berhasil difinalisasi dan dikunci.` });
         } catch (err) {
           res.status(400).json({ success: false, error: err.message });
         }
       });
       ```
    2. Add route `POST /api/bracket/unlock-round`:
       ```javascript
       app.post('/api/bracket/unlock-round', async (req, res) => {
         try {
           const round = parseInt(req.body?.round) || 2;
           const result = RaceManager.unlockRound(round);
           io.emit(`round${round}:unlocked`, { round, timestamp: new Date().toISOString() });
           io.emit('bracket_updated');
           broadcastFullState();
           res.json({ success: true, data: result, message: `Kunci Babak ${round} berhasil dibuka.` });
         } catch (err) {
           res.status(400).json({ success: false, error: err.message });
         }
       });
       ```
    3. Add route `GET /api/bracket/progress`:
       ```javascript
       app.get('/api/bracket/progress', (req, res) => {
         try {
           const round = parseInt(req.query?.round) || 2;
           const progress = RaceManager.getRoundProgress(round);
           res.json({ success: true, data: progress });
         } catch (err) {
           res.status(400).json({ success: false, error: err.message });
         }
       });
       ```
