# Milestone v4.0: Postgres DB Driver + Redis Socket Adapter & API Rate Limiting (Standalone Decoupled)

**Shipped:** 2026-09-20  
**Audit Report:** [v4.0-MILESTONE-AUDIT.md](v4.0-MILESTONE-AUDIT.md)

## Accomplishments

1. **Standalone Decoupled System & Local CSV/JSON Import/Export (Phase 29):**
   - Decoupled tournament system completely from Google Sheets API.
   - Added REST export endpoints for Participants, BTO Leaderboard, and Winners in CSV and JSON formats.
   - Added REST batch import endpoints for Participants and BTO with line-by-line validation.
   - Retained Google OAuth 2.0 and Emergency Offline Login.

2. **PostgreSQL DB Driver & Dual-Database Abstraction Layer (Phase 30):**
   - Developed switchable database driver abstraction (`DB_DRIVER=postgres|sqlite`) in `server/db.js`.
   - Created full PostgreSQL DDL schema (`server/schemas/postgres-schema.sql`).
   - Ensured ACID transaction safety with fallback grace to SQLite WASM.
   - Updated `/api/health` to expose `db_driver` indicator.

3. **Redis Socket Adapter & API Rate Limiting Infrastructure (Phase 31):**
   - Integrated `@socket.io/redis-adapter` and `ioredis` for horizontal multi-node WebSocket scaling.
   - Added auto-fallback to in-memory Socket.IO adapter when `REDIS_URL` is absent/offline.
   - Built API Rate Limiting middleware protecting `/api/auth/*`, `/api/participants/*`, `/api/winners/*`, `/api/bracket/*` with standard HTTP 429 and `RateLimit-*` headers.
