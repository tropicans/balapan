## 4. Cross-Phase Integration & E2E Flows

1. **Authentication & Token Flow:**
   - User signs in with Google OAuth or local emergency login (`client/src/components/auth/LoginScreen.jsx`).
   - Token stored in `localStorage` and managed by `AuthContext.jsx`.
   - `client/src/utils/api.js` automatically attaches `Authorization: Bearer <token>` to all mutations.
   - Backend `authMiddleware.js` validates session, approval status, and role before mutating database state.
   - State mutations automatically trigger `io.emit('STATE_UPDATE', RaceManager.getFullState())` across all displays.

2. **Bracket Lifecycle & Lock Enforcement:**
   - Multi-round bracket (Babak 2, Babak 3 with 21 heats cap, Grand Final) checks dynamic round locks.
   - Public visitors at `/bracket` view live bracket matches in pure read-only mode.
   - Directors execute winners or NO RACE declarations; slot repacking automatically places subsequent winners into open slots (such as Lane C) without gaps.
   - Background Google Sheet sync preserves finished matches and in-progress heats.

3. **Event Isolation:**
   - Switching active events (`setActiveEvent`) cleanly resets operational round status flags (`qualifying_status`, `round_status`) to `'open'`, preventing status bleed across different tournament dates.

## 5. Technical Debt & Deferred Items

The following items are documented in `CONCERNS.md` as non-blocking technical debt for future milestones:
- **PERF-01**: Pure WASM `sql.js` performs synchronous file buffer exports to disk on write queries; consider debounced writes or native SQLite for high-traffic cloud scaling.
- **PROC-01**: Active countdown timers run in Node.js process memory; saving target end timestamps to `tournament_settings` would enable seamless reconnects across server restarts.
- **IOS-01**: iOS WebKit restriction on `navigator.vibrate` and speech autoplay policies (visual cues on Circuit TV and modals remain the source of truth).
